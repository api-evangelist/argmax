# Argmax

> Argmax, Inc. builds on-device inference infrastructure that runs foundation models locally on user devices for privacy, real-time performance, and predictable per-device costs. Products include WhisperKit (speech-to-text), SpeakerKit (speaker recognition/diarization), DiffusionKit (image generation on Apple Silicon), and TTSKit, plus the Argmax Local Server for macOS — a Deepgram Speech-to-Text (Live) API-compatible local transcription server. Backed by General Catalyst.

## APIs

- [Argmax Local Server guide](https://app.argmaxinc.com/docs/guides/using-local-server): Deepgram-compatible local transcription server (WebSocket, default ws://localhost:50060), driven by the @argmaxinc/local-server Node client.

## Authentication

- Argmax API key (ax_ prefix) issued from the Argmax Console; supplied at SDK/Local Server initialization. Device-based licensing keyed on licenseId.
